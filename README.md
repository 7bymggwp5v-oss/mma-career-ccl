# MMA CAREER CCL — prototype jouable

Jeu de carrière MMA fictif, en français, pensé pour les écrans de téléphone.

## Fonctionnalités du prototype
- Création d'un combattant et choix de catégorie/style
- Entraînement en frappe, cardio et lutte, plus récupération
- Combats simulés avec victoire, défaite ou nul
- Argent, popularité, palmarès, classement et ceinture CCL
- Sauvegarde locale dans le navigateur de l'appareil

## Tester
Ouvrir `index.html` dans un navigateur moderne.

## Ajouter à GitHub depuis un téléphone
1. Ouvrir le dépôt `https://github.com/7bymggwp5v-oss/mma-career-ccl`
2. Appuyer sur **Add file** puis **Upload files**.
3. Sélectionner `index.html` et `README.md` extraits de cette archive.
4. Valider avec **Commit changes**.

## À savoir
Ceci est une première version web responsive, pas encore une application native publiée sur l'App Store ou Google Play. La prochaine étape sera de l'héberger puis de préparer une version installable (PWA ou emballage natif). La sauvegarde est actuellement locale à l'appareil/navigateur.
